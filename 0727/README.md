
# 0727 - 권우형의 이력서 (다국어/테마 지원 버전)

0724 버전을 발전시킨 이력서 페이지로, 반응형 2단 레이아웃과 한국어/영어/일본어 다국어 전환, 다크·라이트 테마 전환 기능이 추가되었습니다.

## 주요 구성

- **상단 내비게이션** : 로고, 섹션 이동 메뉴, 언어 선택(KO/EN/JP), 테마 토글 버튼, 모바일 햄버거 메뉴
- **사이드바** : 프로필 사진(스티키 노트 문구 포함), 기본 정보 표, 타이핑 애니메이션, Contact, Skills
- **본문**
  - About : 자기소개
  - Education : 경성대학교(학부 재학중), K-Move 일본과정(수강중)
  - Projects : `재밌는 앱`(DB/CRUD 테스트 영상), `더 재밌는 사이트`(유튜브 임베드)
- **Footer** : 태그라인, 최종 업데이트 날짜
- **맨 위로 이동 버튼**

## 다국어 처리

`data-i18n` 속성과 JavaScript의 `translations` 객체(ko/en/ja)를 이용해 텍스트를 실시간으로 교체합니다.

## 파일 구조

```
0727/
├── index.html      # 이력서 메인 페이지 (다국어 스크립트 포함)
├── css/
│   └── style.css    # 반응형/테마 스타일시트
├── images/           # 프로필 사진
└── dbtest.mp4         # 프로젝트 시연 영상
```

## 사용 기술

- HTML5 / CSS3 (반응형 레이아웃)
- Vanilla JavaScript (다국어 전환, 다크모드 토글, 타이핑 효과, 스크롤 이벤트)

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 확인할 수 있습니다.
