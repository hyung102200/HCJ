
# 0723 - 권우형 포트폴리오 페이지

경성대학교 컴퓨터공학과 재학생이자 백엔드 개발자 지망생 권우형의 개인 포트폴리오 웹페이지입니다. 터미널/코드 에디터 느낌의 다크 테마 디자인으로, 스크롤 진행률 표시와 타이핑 애니메이션 효과가 적용되어 있습니다.

## 주요 구성

- **Header** : 이름, 캐치프레이즈, 타이핑 애니메이션 인트로, 섹션 이동 내비게이션
- **About** : 프로필 사진, 학교/전공/희망 직무 등 기본 정보 표
- **Skills** : Language(Java, Python, C), Database(MySQL, PostgreSQL), Tools(Git, VS Code, IntelliJ)
- **Projects**
  - `TravelBusan` : 부산 관광지·맛집·축제 정보 제공 웹사이트 (HTML, Java, Spring Boot, MySQL)
  - `타닥(Tadak)` : AI 기반 공모전 추천 플랫폼 (Spring Boot, PostgreSQL, Gemini API, HTML)
- **Experience** : 공모전 참여, AI 해커톤, K-Move 과정 이력 표
- **Interests** : 백엔드 개발, AI, 데이터베이스 설계, 문제 해결
- **Contact** : 이메일, GitHub, 전화번호

## 파일 구조

```
0723/
├── index.html      # 메인 페이지
├── style.css        # 전체 스타일 (다크/코드 에디터 테마)
└── images/          # 프로필 및 프로젝트 스크린샷
```

## 사용 기술

- HTML5 / CSS3
- Vanilla JavaScript (스크롤 진행률, 타이핑 효과, 시계 표시)
- Google Fonts (Space Grotesk, Inter, JetBrains Mono)

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 확인할 수 있습니다.
