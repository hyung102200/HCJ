# 0724 - 권우형의 이력서 (기본 버전)

HTML/CSS로 제작한 간단한 개인 이력서 페이지입니다. 이후 버전(0727)에서 다국어·테마 전환 기능이 추가되는 초기 형태입니다.

## 주요 구성

- **My info** : 프로필 사진, 이름/직업/나이/거주지 표
- **About** : 자기소개 문구
- **Contact** : 전화번호, 이메일, 인스타그램, GitHub 링크
- **Skills** : HTML, CSS, Java, Javascript, Python, MySQL
- **Projects**
  - `재밌는 앱` : 캡스톤 디자인 수업에서 진행한 DB 연동/CRUD 테스트 영상 (`dbtest.mp4`)
  - `더 재밌는 사이트` : 유튜브 영상 임베드

## 파일 구조

```
0724/
├── index.html      # 이력서 메인 페이지
├── css/
│   └── style.css    # 스타일시트
├── images/           # 프로필 사진
└── dbtest.mp4        # 프로젝트 시연 영상
```

## 사용 기술

- HTML5 / CSS3 (별도 JavaScript 없음)

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 확인할 수 있습니다.
